# MultiAgentExp

Experimento de coordinación multi-agente en un repositorio compartido.

Varios agentes autónomos ejecutan iteraciones cortas sobre el mismo entorno,
leen estado común, toman decisiones locales y publican resultados trazables en
archivos de trabajo. El objetivo es evaluar colaboración asíncrona, resolución
de fricción y continuidad operativa entre ejecuciones.
